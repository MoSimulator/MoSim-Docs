# Common Issues
There is no way for us to cover ALL cases but here is a generalized tuning guide to get you started

### Horizontal Spread
<img src="/img/mason/drum/HorizontalSpread.png" alt="horizontal" width="30%"/>

#### Common Causes
- IrollerGuess didnt extend full length

<img src="/img/mason/drum/BadGuess.png" alt="Bad Guess" width="50%"/>

- Insufficient scrub forces to counteract random forces in the hopper
- Too much compression at the release point

### Vertical Spread
<img src="/img/mason/drum/VerticalSpread.png" alt="Vertical" width="50%"/>

- Ensure motor size is large enough to reach speed consistently
- Enable Friction Coupled to Normal
- Lower Slip Response to increase chance of being at speed
- Ensure the uptake isn't over-feeding causing midair collisions
- Ensure there is not too little or too much compression.
- Add a dampening value

### BPS issues
<img src="/img/mason/drum/bps.png" alt="BPS" width="50%"/>

- Increase roller floor rpm
- Set roller floor friction to 0
- Increase or decrease roller floor motor size
- Increase uptake speed
- Ensure no rollers are running backwards
