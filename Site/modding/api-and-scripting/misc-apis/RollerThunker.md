Roller Thunkers are an audio tool that can cause a roller to make an audible sound anytime it comes into contact with a certain layer.

<img src="/img/mason/apis/roller_thunker.png" alt="Roller Thunker component" width="50%"/>

Simply attach the script to a roller and add an audio clip.

:::note
If the roller itself already uses an audio clip, do not add a Roller Thunker to it.
:::
